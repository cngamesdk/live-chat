## 二、为什么选择 Live Chat？

### 🚀 技术领先，性能卓越

#### 实时通信架构
采用 **WebSocket 长连接** + **消息队列** 架构，实现毫秒级消息推送：
- ⚡ 消息延迟 < 50ms
- 💪 单服务器支持 10,000+ 并发连接
- 🔄 自动重连机制，断线无感知
- 📊 实时在线状态同步

## 五、快速开始，5 分钟部署

### 前置要求
- ✅ 一台 Linux 服务器（2 核 4G 起步）
- ✅ MySQL 8.0+
- ✅ Redis 6.0+
- ✅ 域名（可选，建议配置）

### 三步部署

#### 第一步：下载安装
```bash
# 克隆代码
git clone https://github.com/cngamesdk/live-chat.git
cd live-chat

# 安装依赖
cd api && go mod download
cd ../h5 && npm install
```

#### 第二步：配置
```yaml
# 编辑 api/config.yaml
mysql:
  host: 127.0.0.1
  port: 3306
  database: live_chat
  username: your_username
  password: your_password

redis:
  addr: 127.0.0.1:6379
```

#### 第三步：启动
```bash
# 启动后端
cd api && go run main.go

# 启动前端（开发环境）
cd h5 && npm run dev

# 或构建生产版本
cd h5 && npm run build
```

✅ **访问 http://localhost:5173 即可使用！**

### Docker 一键部署（即将推出）
```bash
docker-compose up -d
```
